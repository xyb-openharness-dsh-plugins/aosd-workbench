# 设计者章程

状态：M0 已对齐服务主体和约束；研究/场景优先级仍待 G1，不把对齐当成患者验证。

- **代表谁**：成人斯蒂尔病患者及家属。患者是本人感受与授权的主体；家属是可能代记、协助整理的另一个来源，二者不能混写。开发者不冒充患者或临床人员。
- **已确认**：用户于 2026-10-27 答复“患者及家属”；自动领取任务授权 M0–M9 但各 G 闸口必须签认。目标目录为本项目目录，不是病历资料目录。
- **成功改善**：复诊准备少靠记忆，资料能追溯来源，本人/代记/报告/医生答复分得清；低精力时仍可完成最小记录。真实成效尚未验证。
- **怎样研究**：医学原件、公开患者叙述/需求研究、组织资料分层；记录版本与局限；0 访谈如实显示。功能假设不冒用一手引语。
- **如何取舍**：优先患者自己的记录、核对、导出与回看；不为铺满页面加入医生工作站、自动判读或癌症字段。候选一期为同日多轨、代记边界、就诊材料，G1 决定。
- **覆盖**：就诊资料准备、确诊后记录与长期随访；未确诊资料需隔离，不根据症状自动归病。中文、本机优先，公共资料的外发/访问单独标识。
- **医学与 AI**：指南提供公共背景，不推导个人处置；AI 仅整理用户授权的资料、生成候选或问题草稿，不变成医学事实。
- **布局**：工作台中间主区，原生 Agent 右栏，默认关闭，35% 展开、25%–45% 可拖、隐藏可重开；尚未原型或真机验证。
- **互动**：保留已确认答案；其他默认值记录于 DEV-REQUIREMENTS §五。价值/范围变更与 G1/G2/G3 必须留原话签认，不以自动检查替代。
- **设计产物**：BRIEF/SPEC、SCENARIOS、INTERACTION-DESIGN、UI/AGENT-PANE-DESIGN、DESIGN-REVIEW，之后再做 HTML。
- **独立 review**：M1 需要患者视角否决项评审，记录实际 agent/模型、日期与证据；未完成不冒充通过。
- **当前关键取舍**：是否把“患者本人与家属代记的来源边界”作为一期基础合同；建议保留，因为它影响数据、导出、AI 和共享设备的每个环节。
