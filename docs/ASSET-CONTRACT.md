## 决定

- 官方 PDF 存于 `assets/guidebooks/nhc-86-rare-diseases-2025.pdf`，不再是仅本机的 `guidebooks/` 原件。
- 文件 517 页、15,611,195 bytes、SHA-256 `d03fe69585320fea7938bf85bea9ec346a3d5d7671c7d8627fff8393679bbfef`。
- 中国政府网原始 URL 保留为官方来源；本地阅读地址使用随包相对资源，未来服务端映射到 `/assets/guidebooks/nhc-86-rare-diseases-2025.pdf#page=21`。实际路由尚未实现，不写成已可用。
- 疾病概要每个对应条目同时给“本地阅读”与“官方来源”，本地不可用时显示明确降级，不能把 404 页面当 PDF。
- 只读展示，不修改指南正文，不把公开文件存在解释为额外的商业再分发许可。来源/版本/机构随文件保存。
- 本项目此决定不自动修改其他项目或 starter 的默认“原件不入包”规则；M9 作为可选模式回流，须补许可/包体/文件路由/原型逐字符边界。

## 验证合同

1. `npm pack --dry-run --json` 必须列出该 PDF；安装后按同一相对路径读取并核对 SHA-256。
2. 静态资源只接受白名单 manifest 中的名字，不接收任意路径；防止用 `..` 读患者文件。
3. 原型 `file://` 与开发版 HTTP 两种形态分别实测点击，记录状态、content-type、文件头 `%PDF` 与页锚。
4. M2 浮窗中“本地阅读”实际可点，键盘可达；M6 安装后再测，不以源码树成功代替。
5. 公共指南资产与患者资料目录完全分离，不记录患者路径，不将病历打包。
