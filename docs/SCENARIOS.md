# 患者与家属场景清单 v0.1（G1 待签）

日期：2026-10-27。证据：NHC 2025 官方原件、`USER-RESEARCH.md` E01–E14、`FAMILY-COMPARISON.md`。**真实患者/家属访谈 0、临床审核 0**。下列患者视角句均为待访谈核实的设计假设，不是患者原话；G1 签认只能确认产品范围，不能替代患者验证。

## 十条疾病轴 → 患者任务，而非医生工作流

| 疾病轴 | 本病公共事实/研究线索 | 患者/家属要整理的事 | 产品边界 |
| --- | --- | --- | --- |
| 定义与诊断资料 | NHC P17–19：罕见自身炎症性疾病，诊断涉及排除其他疾病 | 保存不同就诊阶段的病名、报告与医生原话 | 不做 Yamaguchi 自测或“可能是 AOSD” |
| 病程与分型 | NHC P18：病程/表现存在差异；具体分型由临床判断 | 按发生时间保留事件与旧病名，不强制每日打卡 | 不自动推分型、活动度或复发 |
| 治疗记录 | NHC P20–21列出药物类别；E01/E08 有长期用药沟通线索 | 分开医嘱、实际用药事件、变更与疑问 | 不把药物类别转成个人方案或调药建议 |
| 症状与功能 | NHC P17–18多系统表现；E01/E02/E05/E08–E10有感受线索 | 本人/代记按日期记录症状、生活和活动影响 | 自述不等于医学结论，不自动归因 |
| 营养与进食 | 本路尚未获得 AOSD 专项患者需求证据 | 一期只保留自愿的生活影响记录 | 不做营养处方、单独一级页或通用癌症营养模板 |
| 心理与家庭 | E02/E04/E05/E08；E12为通用照护间接证据 | 自愿记录情绪/照护影响；代记须本人授权与可核对 | 不做心理诊断；默认私密；不把家属感受写成患者的 |
| 复查与指标 | NHC P18–19列出多类检查；E08有定期监测线索 | 原报告、日期、机构、单位、参考范围、同口径回看 | 不设疾病活动/MAS 风险分；无统一复查频率 |
| 并发症与安全信息 | NHC P20提及 MAS 等严重并发症 | 公共资料层提供有页码的背景；个人资料原样保存并供就诊沟通 | 不做风险计算、分诊或延误就医的“安全保证”；警示文案待临床核对 |
| 临床研究 | M1仅CT.gov宽检索26条登记，含完成/终止/撤回/UNKNOWN；不是M4或招募数 | 二期可保存公共登记线索与待问事项；一期不占位 | 不显示虚构条目，不判入组资格或疗效；未完成中国通道与规范筛选 |
| 费用与资源 | E03强调成本研究不足；E10/E11仅个案行政负担 | 一期仅可选保存费用问题与资源链接 | 不做中国费用推断、报销计算或资源推荐保证 |

## 一期候选场景

| ID | 触发 → 患者/家属动作 → 产物 | 患者视角设计假设（非引语） | 证据/状态 | 失败恢复与验收 |
| --- | --- | --- | --- | --- |
| S01 | 低精力或想补记一次感受 → 最少记录日期、来源和原话 → 一条本人记录 | 我只记一小段，也能留到下次复诊再用 | E01/E02/E07；具体交互待访谈 | 无 AI 可手录；可草稿/稍后补；保存后看板/同日/选材同 ID |
| S02 | 家属协助记录或陪诊 → 先取得对应授权，选择“转述本人”或“家属观察/感受”，记录说话者与录入者 → 一条可补充的代记 | 家人帮我记的内容，要能让医生分清是谁的经历、谁说的、谁录入的 | E05/E06/E12，专项证据不足 | 未获相应授权不得写入患者共享档案；本人/家属补充分别留版本；导出标明三类来源 |
| S03 | 复诊前要还原某天经过 → 选择日期和来源 → 同日四轨视图与详情 | 我想知道那天本人、家属、报告和医嘱分别记录了什么 | R03跨科资料交接（E05/E06等）；四轨交互待验证 | 叙述轨保留本人自述/转述/观察三类标签；跨日/补录不混；并列不推因果；返回原筛选/焦点 |
| S04 | 收到纸质或 PDF 报告 → 手工或显式云解析 → 原件索引与确认指标 | 我希望先看清原文，再决定哪些识别结果能保存 | R04原报告归档（E01/E08/E12/E13间接）；MinerU真实AOSD报告验证0 | 拒绝云/失败/0候选保留原件；缺项为空；拒收零副作用；成功候选可回源 |
| S05 | 多次报告想回看 → 选择原报告指标 → 原值、单位、日期与来源表 | 我想先按原文找到每次报告，不想从曲线猜病情 | NHC P18–19；趋势图缺直接患者证据 | 一期不多指标归一叠加/事件分层/平滑曲线；缺项留空，不把拆组称作临床可比 |
| S06 | 用药或医嘱发生变化 → 记录实际事件与医嘱原文 → 可回溯的变更历史 | 我想知道哪天变了什么、当时医生怎么交代的 | E01/E05/E08–E13；不推功能效果 | 计划≠实际；更正新增版本；无停换药/疗效判断 |
| S07 | 复诊前选材并排序问题 → 导出；就诊后标记已问/未问、记录医生原话与患者理解并关联原问题 → 可回看快照与答复 | 即使没来得及逐项核对，我也想带上原件和问题，诊后还能找到当时的回答 | E01/E06/E11–E13；格式待访谈 | 只有草稿/原件/拒绝云/无AI均可导出；未核对标识贯穿；旧快照内容不变且标过时；诊后不改写旧快照 |
| S08 | 查病名、指南或公共资源 → 查看公共资料与来源 → 本地指南阅读或保存待问事项 | 我想知道这句话出自哪份资料，而不是把不同来源混起来 | NHC原件已核；M1桌面宽检索1次，产品规范查询0；组织可及性未核 | 本地/官方双入口；一期不显示研究匹配或二期占位；未确诊资料不归病 |

## 二期/暂不选

- 多人实时家庭账号与复杂权限：先验证一次代记和授权，不默认共享设备即共享全部内容。
- 营养专页、注射辅助、药品库存、报销计算、工作/法律建议：缺足够患者证据或超出信息整理边界。
- 个体临床试验匹配：一期不设置研究入口、空白栏或匹配占位；二期另行立项评估公共登记线索与待问事项，M4及35号边界另审。
- 统一活动度、复发风险、预警评分、CTCAE 默认分级、诊断自测、治疗推荐：不做。
