## 5. 走查发现并已修复

1. 390px 曾把导航整体隐藏 → 改为保留图标导航栏（可切页），探针复测通过。
2. 整页浮层打开时背景仍可滚动 → 增加 `html.pv-lock` 与关闭后滚动恢复。
3. 疾病概要只给官方链接、未给随包 PDF → 增加 `local` 字段与“本地阅读/官方来源”双入口。
4. `check-probe-coverage` 写死他病种探针、且不识别单行 `ROUTES` → 改为本项目探针并兼容单行数组（属脚手架回流项）。
