## 3. 一期偏离（G1 已签，原型按此实现）

1. 指标只做原报告值/单位/采样日+报告日/来源表；**没有**多指标归一叠加、事件分层或平滑曲线。
2. 疾病概要治疗出口“按文件列举的类别并列”，不写肿瘤病期/线序。

## 4. 仍未验证 / 未实现

- 未装进 DSH Desktop；原生 AI 会话未接通（面板明确标“宿主模拟”）。
- 无生产 schema/API、无真实文件导出、无 MinerU 云端调用、无真实患者资料。
- 窄宽 390 已走查，但读屏、触控、打印到 PDF 未逐项实测；滚动锁定只在 Chromium 内核验证。
- 页面 8 个一级名称与顺序仍是待患者/家属验证的信息架构，不是已确认最终导航。
- 患者/家属访谈 0、临床审核 0。

## 5. 走查发现并已修复

1. 390px 曾把导航整体隐藏 → 改为保留图标导航栏（可切页），探针复测通过。
2. 整页浮层打开时背景仍可滚动 → 增加 `html.pv-lock` 与关闭后滚动恢复。
3. 疾病概要只给官方链接、未给随包 PDF → 增加 `local` 字段与“本地阅读/官方来源”双入口。
4. `check-probe-coverage` 写死他病种探针、且不识别单行 `ROUTES` → 改为本项目探针并兼容单行数组（属脚手架回流项）。
5. 指标表单位曾显示“未印” → 生成器改为单位随指标定义进入观察值，复测显示 `mg/L`。
6. 家属观察记录曾露出内部值 `family` → 统一中文显示映射。
7. 390px AI 面板曾压住品牌与顶栏 → 固定于顶栏下方并同步顶栏高度。
8. 复诊选材曾同时列出原版与更正版 → 每个更正链只列最新版并标“含更正”。
9. 指标来源曾显示内部文档 ID → 改为报告标题并可点击回源。
