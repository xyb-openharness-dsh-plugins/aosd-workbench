# UI 与宿主共创设计 v0.1（G1 待签）

状态：文档草案，无业务 HTML。视觉只以将来 G2 签认的原型为准，本文件不是视觉验收。

## 用户与优先级

患者及家属，低精力时可只完成一件记录；主任务为本机记录、核对、复诊准备，AI 是可选协助。页面名采用患者任务语言，不用“临床工作台/医生评分/病程管理”代替患者视角。0 访谈，命名和优先级仍待验证。

## 页面与内容层级

8 个一级页与二级页见 `FEATURE-INVENTORY.csv`。看板常显最近记录、待核对、待问事项与手录入口；技术设置、医学出处和次要说明渐进披露，但错误、私密排除和云外发不能藏在不明处。

- 顶栏三段：左品牌+版本 chip，中“记录有来源，判断交给医生”，右「?」「AI 对话」「设置」与当前主操作。
- 业务区中间，原生 Agent 右侧默认关闭；展开 35%、25–45% 鼠标/触控/键盘可拖，隐藏可重开，不复制聊天 UI。
- `lib/layout.js` 为面板参数唯一来源；`customFrame` 使用 splitter，split 只走宿主布局，不双状态。
- 原生会话只显式创建/复用归属会话，切换清理旧上下文快照；连接失败仍可手录。未真机前均标未验证。

## 视觉与响应式

品牌暂定小 X 宝，3 个颜色变量待定（G2），其余沿用家族令牌；不以大面积渐变/装饰压过原文。字号基线 12.5–15px，行高和触控目标可用；页脚贴底；`[hidden]{display:none!important}`；减少动效终态可见。

按业务容器宽度：620–760px 顶栏换行且保留导航文字，<620px 才折叠导航文字；AI 优先收起，不能覆盖表格/图表/主操作。`minmax(0,1fr)` 防横溢出，标签+值+注不竖排单字。M2 需多档宽度含 AI 展开实测。

## 图表、折叠与整页

- 一期指标采用原报告值、单位、日期与来源的表格式回看；不做多指标归一叠加、事件分层或平滑曲线，不用“改善/恶化”等判读文案。单位/机构/方法一致也不自动宣称临床可比。图形能力留待患者理解测试与临床审核后另行签认，如启用须满足16号及 Fritsch–Carlson。
- 指标卡如在一期出现，仅展示最近原值、单位、日期与来源，不自动给趋势背面或疗效解释；3D翻转与迷你曲线待后续独立评审。私密点不回传未授权内容。
- 事件折叠卡默认概要，展开看来源/原文/相关记录/患者理解/修订，五块结构按非肿瘤记录语义调整并在 G2 确认；默认收起，打印展开需 printToPDF 实测。
- 报告原文、详情、疾病概要和多字段编辑用整页视图；返回/关闭两个入口，Esc/浏览器返回一层，history唯一真源，焦点/滚动恢复。
- 疾病概要「?」与 README 四段同源，含本地阅读与官方来源；本地 PDF 新标签/浏览器阅读器的返回行为 M2 实测。

## 状态与错误

所有实体有空/单条/多条/缺字段/失败状态；0候选不等于无内容，查询失败不等于无登记。资料目录未选不是“已连接”，AI未连接不是“已发送”，原件存在不是“链接可用”。

云解析前展示文件、服务方、目的与限制；拒绝可手录；Token只掩码，失败保留原件不造候选。删除采用更正链，错误保留输入，长内容只有内容区滚动，标题/关闭固定。

AI只做逐字提取、来源整理和待问清单排版；诱导诊断、风险、调药或紧急度的请求也不得给出个体结论，须提供固定非个体化退出说明。工具不能判断急症，紧急或迅速加重的不适立即按当地急救/医疗机构渠道处理，不等待记录、导出或AI回复。
