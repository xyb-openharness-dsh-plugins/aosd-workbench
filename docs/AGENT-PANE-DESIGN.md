## 布局与状态

- 主工作台居中，原生 Agent 在右侧；默认关闭，顶栏「AI 对话」始终可发现。
- 展开默认35%，范围25–45%，鼠标/触控/键盘 splitter；`lib/layout.js` 唯一参数源。窄屏优先收起，不覆盖业务。
- 五态：未打开/正在连接/已连接（归属会话）/暂不可用/演示降级。未连接不得写“已发送”。
- 隐藏/重开保留业务筛选、表单、滚动和原生草稿；隐藏不结束会话。独立 file:// 演示面板只用于原型，嵌入式只有原生面板。

## 会话与上下文

1. 用户显式点击才检查/创建/复用本工作台归属会话；重复点击/慢响应不多建。
2. `aosd:agent-draft` 携带用户明确选择的提示词与授权上下文，发送按34号 `send:true`；独立形态只演示/复制并说明未接通。只做逐字提取、来源整理与待问清单排版，禁止新增病名、正常异常、复发/并发症、紧急度、调药或疗效判断；固定提示工具不能判断急症，紧急或迅速加重的不适立即走当地急救/医疗机构渠道，不等待记录、导出或AI。
3. 父窗口校验 `event.source` 与 `event.origin`，prompt≤8000；setDraft后重取 snapshot，仅 plain+非空才 submit；失败保留草稿/待回车。
4. 现有草稿/附件/提交状态不覆盖、不合并、不误发；提供复制、追加或取消，保留用户原输入。
5. 无选择内容不发送空草稿；private 默认排除、未确认候选值排除、本机路径排除；AI回复不自动入事实。
6. 切换 subject/工作区使旧上下文快照失效，不删除原生历史；迟到的旧响应不覆盖当前。
