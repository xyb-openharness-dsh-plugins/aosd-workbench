# 成人斯蒂尔病工作台需求起点

状态：M1 草案，多轮独立评审后待最终定点复核；G1 未签。服务对象已于 2026-10-27 由用户明确为**患者及家属**，其余场景优先级与一期范围仍待签认。

## 要改善的事

让患者或家属能把分散的症状叙述、报告、用药变化和医生答复按日期与来源整理好，复诊时能找到依据、说出待问事项。工作台是信息整理与就诊准备工具，不做诊断、风险判断、疗效归因或治疗建议。

## 使用者与边界

- 患者本人：记录自己的感受与资料，决定哪些内容进入导出或 AI 上下文。
- 家属：在协助记录时标注“代记”、记录者与原文；不冒充患者本人叙述。
- 未确诊资料不能与已确诊档案混为一谈；家庭共享设备不等于默认共享全部私密内容。
- 目前真实访谈为 0。开发者提出的“同日多轨、代记来源、就诊材料”是候选方向，不代表患者已排序。

## 候选最小闭环

1. 打开看板，查看最近记录、待核对资料与待问事项。
2. 手工记录一次症状，或选择文件并明确授权后生成待核对候选。
3. 核对日期、记录者、原文、单位与参考范围；缺失项留空，确认后入库。
4. 按日期并列查看自述、指标、用药事件和医生原话，不推导因果。
5. 导出就诊准备材料，并回看到同一份已确认记录。

完成标准不是“页面生成”，而是患者/家属在真实 Desktop 中能走通上述闭环；当前未实现、未验证。

## 明确不做

不做症状测病、疾病活动度或复发风险计算，不做药物调整建议，不将公共临床试验登记解释为个人入组资格，不以医生任务替换患者需要。
