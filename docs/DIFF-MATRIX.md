## 与移植底本和成熟基准的边界

`cervical-workbench` 只提供客户端链路参考，`breast-cancer-workbench` 只提供成熟工程对比。本项目是非肿瘤 R2 形态，不能把肿瘤分期、治疗线、肿瘤终点或相邻风湿病的阈值搬来。

## 待 M1 实证

1. 十条疾病轴逐条来源、场景覆盖和患者视角独立评审。
2. 一级页面名与 cervical/breast 两基准逐项比对；一级重名率定义、分母和实测值待完成，目标 ≤70%。
3. 公共患者叙述、组织和临床研究只作分层证据；不把它们折算为访谈人数或需求排名。
4. 判断“同日多轨记录、代记来源、长期用药事件”是否成立为差异化核心，不能只因与癌症不同就宣称患者价值已验证。
