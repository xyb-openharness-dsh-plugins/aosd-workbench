## 实测一级重名率

候选8页：看板、本人与代记、同日经过、报告与核对、指标回看、用药与医嘱、复诊准备、疾病与资源。

- cervical实际12页：同名`看板/复诊准备`，**2/8=25%**。
- breast实际8页：同名`看板`，**1/8=12.5%**。
- 主口径分母为候选数8，逐字匹配；基准侧补充2/12=16.67%、1/8=12.5%。代码/数组证据与复算见 `FAMILY-COMPARISON.md`、`reference/baselines/navigation.json`、`check-m1-contract.mjs`。重名率不是患者价值证明。

## 不复制项与明确缩减

- 不做FIGO/TNM/肿瘤分期、治疗线/周期、肿瘤终点、CTCAE默认分级、风险/复发/疗效/活动度判断。
- 一期不多指标归一叠加、事件分层、平滑曲线或3D趋势背面；16/24号图表能力后续独立评审。
- 一期无临床研究入口/空白栏/匹配占位；M1桌面宽检索不等于M4完成。
- 营养/心理/费用不为了凑页面扩张：营养只保存原有记录，心理自愿私密，费用仅原始问题/票据；不做中国推断。
- 家庭多人账号、通用复查频率、药物提醒/库存/注射辅助、工作/法律/报销建议暂不纳入。
