# 设置与资料边界设计 v0.1（G1 待签）

状态：草案，未实现真实设置/目录/凭据/云服务。服务主体患者及家属；任何“已连接/已保存/已发送”必须有真实来源。

## 入口与分区

所有业务页顶栏右侧「设置」，打开整页而非小弹窗。四区：资料目录、隐私与代记、云端解析、公共资源与关于。宿主公共设置和原生会话不复制。标题/关闭固定、内容独立滚动，窄屏和键盘可退出，取消无副作用。

## 患者资料目录

- 状态：未选择/检查中/就绪/故障，来源是真实目录初始化结果，不是路径字符串存在。
- 仅接受用户明确选择的具体资料目录；主目录、桌面、下载根、`/tmp` 一律拒绝。当前项目目录不等于患者资料目录。
- 更换目录显示旧资料保留策略；取消不切换、失败不清库、不重置患者数据，卸载不删除。备份/迁移只显式触发。
- 目录路径不进入 AI 草稿、导出、截图或公共日志。当前未指定目录，不显示就绪。

## 代记与私密

- 显示本人/家属记录者及关系；代记需要本人授权范围，不能因共用设备就默认全部可见。
- 私密默认关闭，数据读模型/导出/AI 草稿三出口同一过滤；当次显式授权可撤销并留痕，不把一次授权永久化。
- 多人实时账号不在一期，当前权限原型只验证一次代记/补充/导出，不声称已解决家庭账号。

## MinerU 与云

- 默认 HTTP API v4、pipeline；只在接口明确拒收参数时按合同回退 vlm，显示两种识别局限。无 CLI 包装、无 flash 静默降级。
- Token 来源显式>文件>环境，唯一 JSON 文件、0600/原子写、坏文件不覆盖；界面只显示来源/路径（本机设置内）和掩码，不返回明文或写入日志。
- 每次选文件显示文件名、接收服务、目的、限制/留存说明并主动授权；偏好不替代本次授权。
- 拒绝、无 Token、401、超时、限流、停机：保留原件、提供手录/重试/换Token，失败不产候选。候选逐项核对才入事实。
- 不接受 HTML/md/txt 等不支持格式作为云端 PDF 解析；表格先转竖线表，数量不一致整行放弃，缺单位不补。

## 公共指南与临床参考

- 公共 PDF 固定于 `assets/guidebooks/`，版本/页数/hash/官方来源可见；本地阅读与官方链接分开，失败不互换冒充。
- 公共资产与患者目录分根，白名单文件名，不接受任意相对路径。
- 临床试验区域显示未查/失败/未配置/快照日期/覆盖，不把0结果写成不存在；当前未查询。
- 公共组织资源显示地区、证据性质、核验日期与可及性限制，不自动推荐群组。

保存草稿不覆盖旧配置；取消恢复原值；失败保留输入并说明；敏感凭据不明文。A20/A24/A25/A26：首次无目录、路径拒绝、目录切换取消/失败、私密三出口、云授权拒绝/失效/恢复、公共PDF双入口、窄窗键盘。实际预览与宿主验证均待做。
