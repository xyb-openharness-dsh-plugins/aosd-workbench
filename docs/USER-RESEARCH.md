## M1 输出要求

1. 每条证据记录 URL、作者/机构、发布日期、访问日期、摘录边界和局限；公开原话链接到原文，不改写成“患者都说”。
2. 功能线可附“待访谈核实的设计假设”语句；在获得一手访谈前，不能使用伪装成一手引语的引号或“患者原话”标签。
3. 独立评审专门检查医生任务是否冒充患者需要，任一实质违例即 P0，G1 不签。
4. 未来访谈需知情同意、去标识化、区分患者/家属，并允许只贡献一次场景核对而不参与开发。
