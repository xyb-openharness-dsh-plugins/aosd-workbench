# 成人斯蒂尔病交互路径设计 v0.1（G1 待签）

状态：草案，**未签认，不能据此开 HTML**。依据 starter 28 号、34 号及本项目 SCENARIOS v0.1。28 号 IP10/IP11 的旧“只填不发”与 34 号冲突时，以 34 号现行一键发送为准；自动发送仍只含用户明确选择的上下文，私密默认排除，AI 回复仍是候选。

## 一、总原则

- 手录永远可用，无 AI/未选外部资料目录/拒绝云解析也能完成最小记录；事实统一保存到宿主 `config.root` 的应用专属本机数据库，含稳定ID/revision/review_state，刷新与跨页同源。外部目录只负责原件/导出/备份，不另建病历库；AI 协助为可选择的整理入口。
- 手工入口收在卡片「⋯ 更多」；每页显式编辑入口 ≤1，单张表单 ≤6 字段，数字用 `type=number`/数字键盘语义，单位另列原文。
- AI 只做所选内容的逐字提取、来源整理与待问清单排版 → 结构化候选 → 逐项核对 → 确认才入事实；拒收零副作用。禁止新增个体病名、正常/异常、复发/并发症、紧急度、调药或疗效判断，即使用户诱导也不提供；AI 回复仍是候选，不能替代医生。
- 工具不能判断急症。紧急或迅速加重的不适应立即按当地急救/医疗机构渠道求助，不等待记录、导出或 AI 回复；不自编 MAS 阈值/警示清单，公共安全与扩展医学内容启用前须独立临床审核。
- 本人自述、家属转述本人、家属观察/感受是三种 `content_kind`；`experienced_by`、`speaker`、`recorded_by` 分开，授权未覆盖的内容不得写入共享档案。
- 更正只新增版本，界面写「改这一条」，不使用“不可恢复”的数据库措辞。
- 完成一步回看板；长内容用整页视图，返回与关闭分开，Esc/浏览器返回只退一层。
- AI 按钮消息类型 `aosd:agent-draft`，带 `send:true`；独立 `file://` 只显示明确标注的演示，不冒充原生会话。

## 三、CRUD 双通道矩阵

| 实体 | AI 协助（候选） | 手工（收敛入口/≤6字段） | 红线 |
| --- | --- | --- | --- |
| 本人自述 | 说/整理所选文本→发生日期、原话、生活影响候选 | 「记一段感受」：日期、时间可选、原话、私密、影响 | 不推测病名/活动度/原因；本人原话不改写 |
| 家属代记 | 只整理已允许提供的原话，**不得生成、推断或确认授权** | 步骤1：内容性质/经历主体/说话者/录入者；步骤2：关系/日期/原话；步骤3：本人授权范围；每步≤6字段 | 先取得本人对应授权；三类内容不互写；未授权默认不持久化且不得入共享档案/看板/导出/AI |
| 就诊/报告文档 | 显式 MinerU→候选，不直接写事实 | 「手工补一项」：日期、机构、类型、原文、文件 | 云解析失败不产候选；文件路径不进 AI/导出 |
| 报告指标 | 从已选报告抽取原文/值/单位/参考范围 | 「手工补一项」：原项目名、原文值、数值可选、单位可选、采样/报告日期及精度、机构/方法/参考范围（下一步） | `<0.5`保留原文且数值 null；缺单位不字典补；采样日不冒充报告日；单张≤6字段 |
| 用药事件 | 整理药名/剂量原文/日期/实际或计划 | 「记一次用药或医嘱」：药名、原文剂量、事件类型、日期、原话 | 不计算剂量/疗程，不生成治疗线或调药建议 |
| 医嘱与患者理解 | 整理医生原话与患者自己的疑问分栏 | 「补一段医嘱或理解」：原话、说话者、日期、理解、私密 | 医生结论与患者看法分开；AI 不生成医嘱 |
| 待问事项 | 从已选事实整理问题，发送给原生 Agent | 「写一个问题」：正文、主题、私密 | 问题不代表医学结论；答复单独记录 |
| 就诊快照/导出 | 只排版用户明确选择的材料，不改写为医学结论 | 「准备这次复诊」：已确认或未核对材料/原件、问题优先级、简版/详版预览 | 每项review_state贯穿预览/导出/打印；未核对不变已确认；原件可直接选；三出口私密过滤 |
| 公共收藏/资源 | 只保存公共资料来源与待核实问题 | 「保存这条线索」：来源、日期、备注 | 一期无研究匹配或空白试验占位；M1桌面检索不等于产品已查询 |
| 生活影响/心理自述 | 不主动生成患者感受；只整理用户主动输入 | 「记一段感受」：自愿原话、日期、私密 | 默认私密，不做评分，不自动导出或发送 |

## 五、隐私与导出默认值

| 属性 | 默认 | 改变与撤销 |
| --- | --- | --- |
| `is_private`（心理/亲密关系等敏感记录） | true | 本人逐项改为非私密才按普通记录处理 |
| `family_visible` | false | 本人按内容/范围授权；未授权不进共享档案 |
| `export_allowed` | false | 用户逐项选材；未核对项允许但必须持续标注 |
| `ai_allowed` | false | 用户逐项选择后发送；不将选材自动视为允许AI |

撤销只影响之后的访问/导出/发送，不承诺召回已导出的文件或已发送内容，授权时必须提示。`私密默认关闭`一律改指“出口默认排除”，不是把记录自身默认设为非私密。

## 六、本地指南与整页

- 顶栏「?」与 `disease-resources` 的四段共用一份 primer-data；本地阅读地址 `/assets/guidebooks/nhc-86-rare-diseases-2025.pdf#page=21`，同时给[官方 PDF](https://www.gov.cn/zhengce/zhengceku/202507/P020250710595668350272.pdf)。
- 原型 file:// 用相对资源路径；开发版通过白名单静态路由。不能把用户患者文件置于该公共目录。
- 本地 PDF 使用浏览器内置阅读器/新标签（M2确认）；从整页返回仍按 history 恢复原页面/焦点，不能用假新页破坏栈。
- 折叠卡用于就诊/用药事件“概要→细节”，默认收起；详情含来源、原文、相关记录、患者理解、修订历史，不套用肿瘤五块或治疗线。收/展两态和打印须 M2 实测。
