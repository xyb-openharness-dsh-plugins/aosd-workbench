# 成人斯蒂尔病整页视图清单 v0.1（G1 待签）

状态：设计清单，未实现。规范 32 号，原型四件套 file:// 不使用 ES module import。

## 形态判定

| 交互 | 形态 | 理由 |
| --- | --- | --- |
| 疾病概要/指南说明 | 整页 `primer` | 四段+表格+本地/官方链接，超过1.5屏 |
| 报告原文与核对 | 整页 `document` / `candidate` | 原文、候选、来源定位多区块 |
| 自述/代记/用药/医嘱详情 | 整页 `event` | 来源、原话、修订链、相关记录 |
| 多字段手工编辑 | 整页 `edit` | 需独立滚动和≤6字段分组 |
| 指标放大/同日详情 | 整页 `chart` / `day` | 图表空间与跨轨上下文 |
| 设置 | 整页 `settings` | 目录/私密/云/公共资源分区 |
| 单项确认/小选择 | 弹窗 | 一句话或单字段，不超一屏 |

## 页面树与返回

| key | 从哪进 | 层深 | 返回 |
| --- | --- | --- | --- |
| `primer` | 顶栏「?」或疾病与资源 | L1 | 原一级页/原滚动与焦点 |
| `document` | 报告原件/指标点详情 | L1/L2 | 来源页或同日详情 |
| `candidate` | 待核对卡/报告候选 | L1/L2 | 原候选列表与选择 |
| `event` | 同日事件/用药折叠卡 | L1/L2 | 同日或用药页 |
| `edit` | 页面唯一「⋯更多」编辑入口 | L1/L2 | 原实体页，保留未保存提示 |
| `chart` | 指标放大 | L1 | 指标页 |
| `day` | 看板「看这一天」 | L1 | 看板原位置 |
| `settings` | 顶栏设置 | L1 | 原业务页 |

最深层预计 L2，须显示“主页 › 来源页 › 当前详情”；返回和关闭分别可见；关闭回触发者，Esc/浏览器返回各退一层；`#page=<key>` 深链，未知 key 回主页并警告，不用 replaceState 假退栈。

## 本地 PDF

疾病概要中的“本地阅读”指向随包 PDF 的 `#page=21`，同时保留官方来源。计划用浏览器阅读器/新标签，不伪造一个可滚动的“PDF已打开”HTML；从阅读器回到工作台仍恢复原页面。原型 file:// 与开发版 HTTP 均实测，路由失败给明确降级，不显示 PDF 内容预览伪造成功。
